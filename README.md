## Цели
- Изучение gRPC и protobuf
- Приобретение навыков работы с пакетами `context` и `net/netip`

## Архитектура 
### Клиент
Клиент генерирует случайные IP-адреса, изменяя случайным образом определённые байты:
- для IPv4 - третий байт 
- для IPv6 - восьмой байт

Сгенерированные IP-адреса вместе с временной меткой отправляются на сервер с помощью gRPC и proto-сообщения.

Предполагается, что уже известны botnet-адреса сетей:
1) ipv4 - 192.168.0.0/24
2) ipv6 - 2001:0db8:85a3:0000::/64

Адреса сетей обычных клиентов:
1) ipv4 - 142.168.0.0/20
2) ipv6 - 2001:0db8:12a3:0000::/64

### Сервер 
Сервер слушает порт :8080, принимает proto-сообщения и проверяет, в какие сети выходят полученные IP-адреса. В случае обнаружения адреса из botnet-сети, сервер сохраняет IP-адрес и время обнаружения в базу данных ClickHouse.

## Запуск проекта
Перед запуском проекта необходимо: установить Docker Compose и создать `server/.env`. В файле `server/.env` требуется задать пароль и адрес для базы данных. Поля должны именоваться в соответствии с `server/.env.example`. По умолчанию `DB_ADDRESS = "db"` (в соответствии с именем контейнера), но если запуск проекта будет осуществляться без использования Docker Compose, то необходимо заменить значение поля на адрес базы данных; в случае пустой строки задается адрес `localhost`.
1) Клонирование
```bash 
git clone git@github.com:DimitryAn/Mini-collector.git && cd Mini-collector
```
2) Запуск
```bash
docker compose --env-file ./server/.env up --build
```
